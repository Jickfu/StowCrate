# M5.3 普通绑定保存入口自审

日期：2026-09-03。基线：`a8670c40e7b74526ff41a34acf4f8cd7ebbf86cb`。

本次仅加固已有产品要求的受控迁移边界，不是 M5.3 completion review。按维护者授权，由实现者检查实际 diff、事务路径和回归测试，不再请求外部 ChatGPT Review。

## 问题与修复

`SaveValidatedAggregateAsync` 原先可直接覆盖输出根，即使已有 Current/History 或恢复日志，下一次读取 relative placement 时也会被错误解析到新 root。修改后，在同一 SQLite transaction 内、任何 Source/External/root upsert 之前检查持久状态；不满足条件时抛出带 PlanId/RootKind 的 `StorageRelocationRequiredException`。

## 自审结果

- 检查与写入位于同一事务；调用者绕过 Application workflow 直接调用 repository 也受保护。
- 不过滤 active Plan/unit，因此 inactive recovery state 不能绕过保护。
- 比较 canonical path、comparison key 和 active 状态；省略 root 按原有停用语义处理，不是无条件 NoOp。
- Current 与 History placement 分别保护对应 root；尚存 publish/retention journal 和未完成旧路径/迁移 maintenance 保守保护两根。COMPLETED retention journal 在 compact 前仍具有 reconciliation authority，不能忽略。
- 原根不变时允许其他 binding 更新；无受保护状态的 root 保留初始配置编辑能力；不检查其他 Plan 的 journal。
- 不访问、移动或删除备份文件，不修改 baseline、ArchiveVersion 或 schema。

回归覆盖：Current/History placement、PREPARED/COMPLETED publish、PREPARED/COMPLETED retention、三类 maintenance、inactive Plan、路径与 comparison key 变化、省略/停用、拒绝后重开数据库保持原值、其他 binding 可修改，以及无关 Plan 不干扰。

## 未完成范围

这一 guard 不是迁移授权，也不实现物理 inventory。已有 metadata-only output reorganization port 尚不能作为用户可调用的物理迁移入口。M5.3 后续仍需 journal/互斥协议、目标身份与完整性验证、原子 metadata switch、post-commit cleanup 和 crash recovery；新增 relocation journal 后也必须纳入普通保存的互斥检查。不得以本次自审替代整个 M5.3 完成门槛。
