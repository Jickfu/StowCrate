# M5.3 路径保留释放自审

基线：`257e9b26a9a48f4272f96d8d3ae67b50ffc1688a`，该提交 CI 已通过。本轮提供独立 completion probe 和 compaction 事务，不在启动时自动执行，不新增 schema，也不宣称完成 M5.3。

释放要求 durable Completed、transaction/revision CAS、完整 manifest/progress/device/reservation、当前新 binding、完整 placement/ArchiveVersion、跨 Plan 根安全及 maintenance 互锁。物理端现场验证所有旧/新根 native identity（含空根）、目标 identity/SHA-256/length、旧路径和 temp absence、目录 barrier；返回前再次重验 namespace。缺失根/祖先不视为可信 absence，重现文件不删除，其他未知文件不认领。物理检查不生成可缓存授权，不宣称跨文件瞬时快照或抵抗所有 hostile races。

repository 在同一 SQLite 事务先删除本事务 reservation 再删除 journal，提交前故障/取消全部回滚。新 binding、Current/History placement、baseline 和 ArchiveVersion 不变。普通互锁只有在事务真正提交后才解除；失败不提前释放任何根。该操作不删除文件或目录，已完成日志被压缩移除后不再用于后续恢复授权。

新增 13 项测试：只读物理核验的正常、旧/temp 重现、目标字节漂移、根替换、barrier 不可用与取消；repository 的正常、未完成阶段、revision、物理故障、中途数据库故障与取消。真实文件 + SQLite 组合测试延伸至 compaction，核验 reservation/journal 移除而目标 bytes 与 baseline 保持。所有操作仅涉及私有测试 fixture，没有释放或删除用户真实备份的数据/日志。

验证：最终独立 dotnet build 零 warning/error；最新完整测试 500 项通过（Core 81、Application 85、Architecture 10、Archiving 50、Infrastructure 274）。中途重叠构建曾因 testhost 占用 DLL 出现重试警告，待测试结束后独立构建已消除。EF 无 pending model changes，git diff --check 通过。测试注入 barrier，不冒充突然断电或真实跨卷验收；本轮跨平台结果以新提交 CI 为准。
