# M5.3 manifest v2 自审

旧 manifest 强制要求 execution 摘要，而迁移已使用独立配置 checkpoint；把配置摘要填入旧字段会混淆语义。本次新增不含 ExecutionDigest 的 manifest v2，并把 v1 字段在代码中明确命名为 LegacyExecutionSemanticDigest。旧构造入口仅保留 v1 兼容，不将历史摘要用作当前配置校验。

manifest、progress、configuration 各有独立 payload 编码版本；表级 ProtocolVersion 仍代表既有 transfer 状态协议 1。表结构未变，schema 仍为 6，无数据迁移或旧日志改写。旧程序遇到 v2 必须按其现有未知版本拒绝行为停止，不承诺旧程序可以恢复新日志。

reader 在 hash 校验后读取明确 Version，再分别使用 v1/v2 closed-world DTO，最后校验 canonical 重编码。v1 固定样例逐字节往返保持；v2 不允许旧字段（包括 null），未知/重复版本、字段缺失、字符串版本、错版 reader 和 hash 错误均拒绝。版本由不可变模型的 legacy 字段是否存在决定，无法构造 v2 + legacy digest 混合状态。

v2 Begin 必须携带 configuration observation，仓储在同一事务重验并保存 checkpoint。v2 日志读取发现 checkpoint 缺失视为损坏，不补签、不释放 reservation。v1 的历史兼容和缺少 checkpoint 时拒绝提交的规则继续保持。

真实文件/SQLite 的迁移组合测试切换到 v2，覆盖复制、发布、提交、恢复、清理及 compaction；既有 v1 测试和迁移字节保持测试保留。新日志重开数据库确认编码版本、无旧摘要、存在 checkpoint；模拟移除 checkpoint 后读取明确拒绝。

本次不声称完整 Begin 用户入口已完成，也不改变 portable backupplan、baseline、ArchiveVersion 或 native comparison/durability 的保证范围。完整物理 preflight 与入口装配仍待实施。

验证：dotnet build --no-restore 零警告/错误；dotnet test --no-build 报告 667 项通过（Infrastructure 408）；git diff --check 通过。组合测试沿用明确标注的比较能力/barrier 替身，原生能力仍由既有 CI gate 单独验证。
