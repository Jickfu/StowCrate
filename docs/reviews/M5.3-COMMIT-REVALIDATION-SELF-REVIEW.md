# M5.3 提交前全量物理重验自审

基线：`bbe5aaa739e28cb445eb2a3fed1f2db69f4a5b18`。本轮只交付物理提交门槛，不宣称 metadata switch 或 M5.3 已完成。

核对事项：仅接受 TARGETS_DURABLE；manifest/progress 集合一一匹配；所有 root（包括零 placement）都验证 native identity；每个旧/新 artifact 验证 identity、SHA-256 与 length；拒绝重新出现的 temp；目标已有目录逐级完成 barrier；缺失目录不创建；返回前再次全量 namespace/identity 验证。失败/取消不写 SQLite、不删除/移动归档，不推进 baseline。

重验只代表本次观察，不产生可持久复用的提交 token，不能替代紧邻执行的 authoritative semantics 重读与 repository CAS。逐文件验证不是跨文件瞬时快照，无法消除主动 hostile race；物理适配器也不能独自证明调用方 journal 确实来自 durable store。

测试新增完整集合/错误阶段、manifest 集合不匹配、多 artifact、source/target 同长度损坏、相同 bytes 不同 native object、temp 重新出现、缺失父目录、barrier 不可用、取消和空根替换。SQLite 切换事务、File-backed drift gate、启动恢复与清理仍待后续实现。

本地验证：`dotnet build --no-restore` 0 warning/error；`dotnet test --no-build --no-restore` 405 项全部通过，物理迁移测试合计 18 项。基线提交的 CI run `33739970181` 已通过；这不代表本轮新增提交的 CI 结果。
