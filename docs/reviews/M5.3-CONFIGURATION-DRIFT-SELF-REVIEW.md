# M5.3 配置漂移检查自审

基线：`65fa31c96ae5fa5a25c4ccb72d23f58ff6133495`。维护者同意无关配置变化不阻断搬迁、identity/layout/root drift 或配置失效则拒绝继续。

实现使用独立版本化 canonical identity/layout fingerprint，包含 PlanId、Source identity/output path、declared Unit identity/source/path/rule source/effective format、输出编码与默认格式。默认格式覆盖离线时未 discovery 的 FILE_MANAGED 单元。名称、说明、调度、过滤规则、压缩级别不进入该投影；显式相同格式与继承格式等价。配置读取器每次重读，检查 active、authority/registration path 与迁移指纹，忽略无关的完整配置指纹及 revision 变化。

本轮不修改 schema、不重解释旧 journal 的 ExecutionSemanticDigest，也不声称 reader 检查了 local roots。根路径与 reservation/CAS 检查保留在独立事务门槛。metadata switch、持久化新指纹、启动恢复与旧副本清理仍未接入。

测试覆盖 15 种 pure fingerprint 变体，以及真实 Managed/File-backed 更新、无关名称变化放行、输出布局变化拒绝、无效/缺失/身份不符文档不回退。返回观察对象不是 durable commit permission。

验证：`dotnet build --no-restore` 0 warning/error；全部 427 项测试通过。前一提交 CI run `33743674207` 已通过；本轮新增提交的 CI 单独跟踪。
