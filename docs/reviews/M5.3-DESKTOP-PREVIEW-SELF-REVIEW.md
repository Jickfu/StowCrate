# M5.3 桌面存储维护预览自审

主窗口从 Avalonia 模板切换到真实存储维护预览。通过 DI 装配组合适配器和 ViewModel；已有配置库打开、权威方案读取、路径解析及目标预检复用既有用例。仅显示启用方案，名称与 ID 同时展示以区分同名方案。不存在的库拒绝打开，不创建空库；已有库可能执行既有结构升级，入口已提示。

仅预览：没有 Begin、Resume、Compact 调用，也不在打开配置库时自动恢复归档。预检保留原有容量、比较规则、目标根存在门槛；平台不可用明确报告。用户必须预先创建目标根。ViewModel 不引用基础设施实现、不判定物理安全；后台检查不阻塞界面，输入运行期间锁定，取消后恢复操作。切换库/方案/目标清除旧结果。

新增 App.Tests 使用 Avalonia 12 对应的 xUnit 3 headless 框架，其他项目继续使用 xUnit 2。验证窗口实际加载和渲染、初始禁用状态、库切换、目标修改使结果失效、取消、缺失根和未知比较能力提示，以及缺失配置库不被创建。实际 PNG 渲染已人工检查；不把 headless 验证视为原生文件选择器或完整跨平台迁移验收。

执行/恢复/compaction 界面、其他平台比较能力、Output Reorganization 尚未完成。此增量不宣称完整产品主配置树、备份编辑器或迁移执行界面已完成。

验证：最终 dotnet build --no-restore 零警告/错误；既有 684 项测试全量通过，最终 App.Tests 7 项通过；git diff --check 通过。渲染图保存在忽略目录 artifacts/ui/storage-maintenance.png。
