# M5.3 桌面迁移恢复自审

新增只读日志读取与显式恢复入口。读取展示原 transaction UUID、revision、阶段、条目数量及冻结旧/新根；不发出任何恢复调用。停用但持有日志的方案也可选择。界面没有新建日志或释放 reservation 的入口。

执行必须针对已读取事务明确确认复制/提交/旧副本清理的结果，取消不会回滚已提交迁移。只将冻结 Plan/transaction 传给既有 ResumeAsync，上方新目标不参与恢复。App 组合适配器装配真实物理服务，能力不满足仍由既有应用协议拒绝；没有平台降级。

执行前清除可重复使用的日志选择与确认，禁止自动重放；后续操作需要重新读取。结果分别显示 ResumeRequired、CleanupPending、CompletedReservationsRetained、NotFound 和 OutcomeUnknown。异常与取消不声称事务回滚，成功提交后的返回结果不被晚到的取消覆盖。绑定可能变化时改为刷新提示，不继续展示旧根为最新事实。

Headless 测试覆盖未确认不能恢复、原事务不受新目标影响、四类结果、切换库清除授权、Completed 禁用、异常/取消不重试，以及真实窗口恢复区域渲染。物理复制/清理正确性继续由 Application/Infrastructure 的真实文件与 SQLite 组合测试负责。当前原生文件选择器未自动验收，测试渲染图不代表真实迁移执行截图。

验证：dotnet build --no-restore 零警告/错误；dotnet test --no-build 共 700 项通过（App 16、Infrastructure 425）；git diff --check 通过。恢复区域 PNG 已渲染并人工检查。
