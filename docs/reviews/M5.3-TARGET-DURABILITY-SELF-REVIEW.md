# M5.3 目标目录持久化预检自审

新增独立预检端口与物理实现，对冻结 manifest 的全部目标根和现存父目录执行已有目录屏障。空集合仍检查根；缺失子目录保持缺失。每次屏障前重新捕获整个父链，屏障后验证当前 identity，结束后重验集合和 final/temp absence。目录不再存在、变为链接/文件、新增或被替换均失败，不创建 journal、目录或探测文件。

屏障返回不可用使用 RELOCATION_TARGET_DURABILITY_UNAVAILABLE；其他 I/O 与取消保持失败。检查仅反映当前现存目录的屏障能力，不证明写权限，不缓存 durable authority，不替代 Stage/Publish 的真实写入后屏障，不扩大平台支持。主动 hostile filesystem race 和断电验收仍不在本测试证明范围。

八项真实目录测试配合明确注入的 barrier，覆盖缺失父目录、现存父目录、空清单、能力不可用、父目录新增/替换、目标出现和取消，验证旧 bytes 保留且无临时文件。完整 Begin 编排、应用入口及其他平台比较能力继续待办。

验证：dotnet build --no-restore 零警告/错误；dotnet test --no-build 共 675 项通过（Infrastructure 416）；git diff --check 通过。
