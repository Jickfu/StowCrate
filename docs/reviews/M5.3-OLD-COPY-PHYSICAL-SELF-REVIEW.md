# M5.3 旧副本物理清理自审

基线：`d95fc0a4bb8a32ee949d882917f0a60ee32b9086`。本轮新增独立 IStorageRelocationOldCopyStore，不新增 SQLite cleanup progress 或释放 reservation，不宣称 M5.3 完成。

清理仅接受 MetadataCommitted、完整 manifest/progress 对应关系和指定 VersionId。先验证目标及旧 root/ancestor/object、identity/SHA-256/length，探测旧父目录 barrier，再重验目标/旧对象，最后仅删除 exact file。旧文件已不存在时只做 absence reconciliation；OldCopyAbsent 已记录后重现的文件不再删除。缺失 ancestor、root replacement、未知对象或内容变化均安全失败。

删除之后忽略 caller cancellation，完成 parent barrier 与 absence re-proof 后返回绑定 transaction/Plan/revision/artifact/native identities 的 proof。proof 不单独授权数据库写入，未来协调器必须核对当前新 binding/placement 和 durable journal。任何失败不回滚新根、不删除未知 temp/文件/目录。原生路径最后检查仅检测正常替换漂移，不宣称绝对抵抗 hostile races。

测试覆盖 exact cleanup/unknown preservation、pre-commit 拒绝、旧/新 bytes 与 identity/root replacement、删除后 barrier 失败再重试、barrier 不可用、预取消、删除后取消、已记录清理后的路径重现。真实文件/SQLite 组合测试从 durable commit 返回的 journal 调用物理清理，并确认新 binding 和未完成日志仍保留；barrier 为测试注入，不冒充实际断电证明。

验证：build 0 warning/error，全部 450 项测试通过，物理迁移测试 30 项。前一提交 CI run `33775899475` 已通过。本轮只在测试的私有临时目录执行删除，未操作用户真实备份。
